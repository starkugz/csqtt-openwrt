# Компоненты и платформы

| Компонент | Версия | Пакет |
|---|---|---|
| Панель CSQTT | 2.5 | `luci-app-csqtt` |
| Клиентское ядро | 2.5.3 | `csqtt-core-2.5.3` |
| Клиентское ядро | 2.1.9 | `csqtt-core-2.1.9` |

Панель необязательна и имеет архитектуру `all/noarch` отдельно для каждой линии OpenWrt. Для ядра нужен пакет точной архитектуры устройства.

| OpenWrt | Формат | Архитектуры |
|---|---|---|
| 24.10.8 | IPK / opkg | Cortex-A53 Filogic, x86-64, ARM64 generic, Cortex-A7, MIPS MT7621 |
| 25.12.5 | APK / apk | Cortex-A53 Filogic, x86-64, ARM64 generic, Cortex-A7, MIPS MT7621 |
| SNAPSHOT | APK / apk | Cortex-A53 Filogic |

Установщик выбирает доступный файл по системе. Для установки необходимо достаточно свободного места; наличие подходящего процессора само по себе не гарантирует, что пакет поместится во flash.

Ядро исходного проекта CSQTT — работа amurcanov. Интеграция с OpenWrt и редакция панели — starkugz. [Лицензия](../LICENSE) и [обязательные уведомления](../NOTICE.md) сохраняются.
