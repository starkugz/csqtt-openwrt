# Панель CSQTT 2.5

Панель устанавливается отдельно от ядра. Номер панели **2.5** не является версией системного LuCI; фактическая версия работающего ядра показана в «Статусе».

| Раздел | Назначение |
|---|---|
| Статус | Соединение, трафик, управление службой и доступные средства диагностики |
| Серверы | Добавление, импорт, изменение профилей, ручное подключение и приоритеты |
| Журнал | Просмотр, фильтрация, скачивание и очистка журнала |
| Настройки | Параметры службы и автоматического выбора сервера |
| CAPTCHA | Задания, необходимые для авторизации |
| О программе | Версии компонентов, доступные ядра и обновления |
| Поддержать | Публичные реквизиты поддержки проекта |

В профиле выбирается ветка **2.1.9** или **2.5.x**; для неё должно быть установлено соответствующее клиентское ядро. При недоступном ядре показывается причина. Автоматической подмены протокола нет.

Пустое поле сохранённого секрета оставляет прежнее значение. Показывайте и копируйте секреты только по необходимости; не публикуйте их.
