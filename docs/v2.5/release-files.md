[CSQTT 2.5.3](https://github.com/starkugz/csqtt-openwrt/releases/tag/v2.5.3): клиентские ядра **2.5.3** и **2.1.9**, необязательная панель **CSQTT 2.5**.

- SNAPSHOT: используйте только пакет для указанной в имени архитектуры и линии.
- Установщик автоматически подбирает доступные пакеты по устройству.
- `SHA256SUMS` содержит контрольные суммы пакетов.
