# CSQTT для OpenWrt

CSQTT подключает роутер OpenWrt к серверу CSQTT. Выпуск `v2.5.3`
содержит клиентские ядра **2.5.3** и **2.1.9**, необязательную панель LuCI
**CSQTT 2.5** и установщик сервера Linux.

## Возможности текущего комплекта

- **Клиентское ядро 2.5.3.** Основной комплект OpenWrt переходит на
  транспорт 2.5.3. Встроенный Gooby можно включить для TURN по TCP/TLS.
- **Панель CSQTT 2.5.** Обновлены экран статуса, редактор серверов и журнал.
  В разделе «О программе» можно проверить выпуск на GitHub и обновить
  панель или ядро по отдельности.
- **Пакеты для MIPS MT7621.** Добавлены IPK для OpenWrt 24.10.8 и APK
  для OpenWrt 25.12.5.
- **Удаление ядра с сохранением настроек.** При удалении единственного ядра
  служба останавливается, а панель, конфигурация и профили остаются.
- **Сервер Linux 2.5.3.** В меню установки он сменил 2.5.1 и доступен
  для x86-64, ARM64 и ARMv7. Сервер 2.1.9 по-прежнему доступен для x86-64.

## Выберите, что установить

- **Роутер OpenWrt.** Запустите короткую команду ниже.
- **Сервер Linux.** Используйте [установщик VPS](server.md).
  В меню доступны сервер 2.5.3 для x86-64, ARM64 и ARMv7 и сервер 2.1.9
  для x86-64. См. [установку сервера](server.md).

## Установка с GitHub

Выполните на роутере по SSH от root. Выберите ядро с панелью, только ядро или только панель.

```sh
wget -T 30 -qO- https://raw.githubusercontent.com/starkugz/csqtt-openwrt/main/install.sh | ash
```

Для выбора версии панели без ядра см. [команды для панели](#только-панель-luci). Установщик определяет
линию OpenWrt и архитектуру и сверяет контрольные суммы пакетов.

На OpenWrt с APK короткий установщик при необходимости добавляет
зависимости выбранных компонентов из репозиториев вашей системы,
включая `coreutils-timeout` и `ucode-mod-socket` для панели. Для
скачивания зависимостей нужен доступ к репозиториям OpenWrt.

## Пакеты OpenWrt

| OpenWrt | Формат | Архитектуры ядра |
|---|---|---|
| 24.10.8 | IPK через `opkg` | Filogic Cortex-A53, x86-64, ARM64 generic, ARMv7 Cortex-A7, MIPS MT7621 |
| 25.12.5 | APK через `apk` | Filogic Cortex-A53, x86-64, ARM64 generic, ARMv7 Cortex-A7, MIPS MT7621 |
| Snapshot | APK через `apk` | Filogic Cortex-A53 |

Для каждой линии предусмотрен отдельный пакет панели `all/noarch`.

## Установка скачанных пакетов

Скачайте пакеты своей линии и архитектуры, а также `SHA256SUMS`
из того же выпуска.

APK этого выпуска устанавливаются с параметром `--allow-untrusted`,
который разрешает установку пакетов, чьей подписи роутер не доверяет.
При ошибке проверки остановитесь.

В каталоге с полным комплектом выполните `sha256sum -c SHA256SUMS`.
Если скачали только нужные APK, проверяйте каждый выбранный файл
по точному имени из ведомости. Пример для OpenWrt 25.12.5 и Filogic A53.

```sh
core='csqtt-core-2.5.3-openwrt-25.12.5-mediatek-filogic-aarch64_cortex-a53.apk'
panel='luci-app-csqtt-2.5-openwrt-25.12.5-all.apk'

verify_file() {
    checks=$(awk -v name="$1" '$2 == name { print; count++ } END { if (count != 1) exit 1 }' SHA256SUMS) || return 1
    printf '%s\n' "$checks" | sha256sum -c -
}

verify_file "$core" && verify_file "$panel" &&
    apk update && apk add --allow-untrusted --force-non-repository "./$core" "./$panel"
```

Для одного компонента проверьте и передайте в apk только его файл.
Для IPK сверяйте SHA-256 тем же способом и устанавливайте через
`opkg update && opkg install ./имя-пакета.ipk`.
Если роутер работает без интернета, заранее установите зависимости
пакета для своей версии OpenWrt.

## Первое подключение

1. Получите у владельца сервера ссылку `csqtt://…`. В LuCI откройте
   **Службы → CSQTT → Серверы → Импортировать ссылку**. Для ручной настройки
   добавьте сервер, укажите его адрес с портом, пароль и данные VK,
   необходимые для выбранного режима.
2. Включите сервер. В разделе **Настройки** включите CSQTT и сохраните
   настройки. Затем откройте **Статус** и нажмите **Запустить**.
3. Когда появится «Подключено», нажмите **Проверить** и дождитесь
   результата «Трафик проходит». Если запрошена CAPTCHA, откройте
   одноимённую вкладку. Для ручной проверки VK используйте «Проверить хеши».
4. Если нужен доступ для устройств в LAN, направьте нужные соединения
   через `csqtt0` средствами своего прокси или правил маршрутизации.
   CSQTT поднимает интерфейс туннеля. Настройки WAN, системного DNS,
   маршрутизации и firewall задаёт администратор роутера.

Без LuCI профиль можно импортировать по SSH. Подставьте свою ссылку.

```sh
csqtt profile import 'csqtt://…' --id myserver --commit &&
csqtt profile enable myserver &&
csqtt profile use myserver &&
uci set csqtt.main.enabled='1' &&
uci commit csqtt &&
/etc/init.d/csqtt restart
```

Для автозапуска после перезагрузки роутера выполните
`/etc/init.d/csqtt enable`.

## Панель и обновления

Откройте **Службы → CSQTT**.
Для обновления из LuCI используйте «Проверить обновления» в разделе
«О программе», затем подтвердите нужный компонент. Установщик
сверяет SHA-256 по подтверждённому плану. Обновление ядра перезапускает
службу. Для отката заранее сохраните установочные пакеты и резервную
копию конфигурации.

## Если что-то не работает

| Симптом | Что проверить |
|---|---|
| Роутер не скачивает с GitHub | Проверьте DNS, время и исходящий HTTPS к GitHub. Если с ПК файлы скачиваются, перенесите пакеты и `SHA256SUMS` на роутер и используйте ручную установку выше. |
| APK сообщает об отсутствующей зависимости | Проверьте доступ к репозиториям своей версии OpenWrt. Короткий установщик загружает зависимости оттуда. Пакет `kmod-tun` должен подходить к ядру текущей прошивки. |
| Пакет не подходит | Сверьте `ubus call system board`, архитектуру и формат пакета с таблицей. На 24.10 нужен IPK, на 25.12 и Snapshot — APK. |
| Недостаточно места | Проверьте `df -h /overlay /tmp`. Ориентируйтесь на объём, который установщик выводит перед операцией. Для обновления требуется дополнительное место под установку и откат. |
| CSQTT запущен, но подключения нет | Запустите `csqtt doctor`. Сверьте адрес и порт, пароль, активный профиль и данные VK. Проверьте вкладки CAPTCHA и Журнал. |
| CSQTT подключён, но сайты на устройствах LAN не открываются | Сначала проверьте туннель со страницы «Статус». Если он работает, проверьте на роутере правила направления трафика через `csqtt0` и DNS, который используют устройства. |
| Не совпадает SHA-256 | Заново скачайте файл и ведомость из одного выпуска. Запускайте установку после успешной сверки. |

Команды диагностики по SSH:

```sh
/etc/init.d/csqtt status
/etc/init.d/csqtt doctor
ip -4 addr show csqtt0
csqtt log tail -n 50
```

[Диагностика загрузки, ошибок APK и импорта профиля](troubleshooting.md#установка-и-импорт-профиля).

## Установка отдельных компонентов

Основное меню предлагает:

1. Ядро 2.5.3 и панель CSQTT 2.5.
2. Только ядро 2.5.3.
3. Только панель CSQTT 2.5.
4. Ядро 2.1.9 и панель CSQTT 2.5.
5. Только ядро 2.1.9.
6. Удаление компонентов.

Пункты установки 2.1.9 доступны, когда в выпуске есть пакет для вашей
линии OpenWrt и архитектуры. Уже установленные актуальные компоненты
пропускаются; более старые обновляются. Выбор ядра в меню определяет
устанавливаемую ветку; автоматической подмены протокола профиля нет.

## Выборочное удаление

Откройте «Удаление компонентов» в основном меню либо запустите:

```sh
wget -T 30 -qO- https://raw.githubusercontent.com/starkugz/csqtt-openwrt/main/install.sh | ash -s -- uninstall --menu
```

Доступны отдельные действия:

- Только панель: установленные ядра продолжают работу.
- Только ядро 2.5.3: панель и ядро 2.1.9 остаются.
- Только ядро 2.1.9: панель и ядро 2.5.3 остаются.
- Оба ядра: панель остаётся.
- Панель и все ядра.

Конфигурация и профили сохраняются. Отсутствующий компонент пропускается.
После удаления последнего ядра служба и туннель останавливаются.
Если остаётся другое ядро, работа зависит от совместимости выбранного
профиля: скрипт не меняет его протокол молча. Для удаления из уже скачанного
установщика доступ к GitHub не требуется. Пункт 0 отменяет действие.

## Удаление и восстановление

Удаление последнего клиентского ядра останавливает службу и удаляет
интерфейс `csqtt0`. Панель и `/etc/config/csqtt` сохраняются. Для
возобновления работы переустановите ядро и запустите службу.

Если остаётся второе установленное ядро, выберите профиль совместимой с ним
ветки. Профиль удалённого ядра не переключается на другой протокол молча.

Для удаления только панели выполните команду по SSH:

```sh
wget -T 30 -qO- https://raw.githubusercontent.com/starkugz/csqtt-openwrt/main/install.sh | ash -s -- uninstall --set panel
```
Служба CSQTT продолжит работу.
Если после удаления LuCI ещё показывает пункт CSQTT, выполните
`/etc/init.d/rpcd reload` и обновите страницу.

Текущий комплект предлагает ядра **2.5.3** и **2.1.9**. После удаления
одной ветки для оставшейся нужен соответствующий профиль. Если после
удаления старого пакета 2.1.9 исчезли точки входа, а ядро 2.5.3 осталось,
их можно восстановить:

```sh
/usr/lib/csqtt/core-2.5.3/activate.sh install 2.5.3 &&
    /etc/init.d/csqtt start
```

## MT7621

Используйте ядро `ramips/mt7621` для архитектуры `mipsel_24kc`.
Перед установкой проверьте свободное место в `/overlay` и `/tmp`.
Для ядра и панели нужен примерно 27 МиБ свободного места в `/overlay`
при первой установке и 51 МиБ при обновлении.
