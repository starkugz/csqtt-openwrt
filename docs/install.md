# Установка CSQTT 2.5 на OpenWrt

Выполните по SSH от root:

```sh
wget -T 30 -qO- https://raw.githubusercontent.com/starkugz/csqtt-openwrt/main/install.sh | ash
```

Меню предлагает ядро **2.5.3** или **2.1.9** с панелью **2.5**, отдельное ядро, только панель и выборочное удаление. Архитектура и формат пакета определяются автоматически.

[Подробная установка и первоначальная настройка](install-v2.5.3.md) · [Сервер Linux / VPS](server-v2.5.3.md).

Для прежней панели предусмотрена отдельная [инструкция 2.0](v2.0/README.md).
