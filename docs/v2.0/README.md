# Предыдущая панель CSQTT 2.0

Эта страница относится только к панели **2.0** из [прежнего выпуска](https://github.com/starkugz/csqtt-openwrt/releases/tag/v2.0). Текущая панель — [CSQTT 2.5](../install-v2.5.3.md).

Для установки только панели 2.0 выполните по SSH от root:

```sh
wget -T 30 -qO- https://raw.githubusercontent.com/starkugz/csqtt-openwrt/main/install.sh | ash -s -- 2.0
```

Для просмотра плана добавьте `--dry-run` после `2.0`. Команда выбирает панель из старого выпуска, ядро устанавливается отдельно. Перед заменой панели сохраните конфигурацию.

Для актуальной панели используйте ту же команду с `2.5` вместо `2.0`.
