# Замена панели CSQTT 2.0

Для повторной установки прежней панели используйте [команду версии 2.0](install.md). Для перехода на текущую панель используйте [инструкцию 2.5](../v2.5/install.md).

Конфигурация сохраняется. Выбирайте только панель, если не требуется переустанавливать ядро. После замены обновите страницу LuCI.
