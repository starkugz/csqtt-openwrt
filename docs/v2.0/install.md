# Установка панели CSQTT 2.0

Это предыдущая версия панели. Для текущей используйте [CSQTT 2.5](../v2.5/install.md).

Выполните по SSH от root:

```sh
wget -T 30 -qO- https://raw.githubusercontent.com/starkugz/csqtt-openwrt/main/install.sh | ash -s -- 2.0
```

Команда устанавливает только панель из [выпуска v2.0](https://github.com/starkugz/csqtt-openwrt/releases/tag/v2.0). Ядра и сетевые настройки не переустанавливаются. Для просмотра плана добавьте `--dry-run` после `2.0`.

Для возврата текущей панели замените `2.0` на `2.5`. Перед заменой сохраняйте конфигурацию. Установка старой панели не означает переход ядра на старую версию.
