# Установка предыдущего комплекта CSQTT 2.0

Панель **2.0**, прежние клиентские ядра **2.1.9** и **2.5.1**. Это отдельный выпуск; актуальный комплект описан в [документации 2.5](../v2.5/README.md).

Выполните на роутере OpenWrt по SSH от root:

```sh
wget -T 30 -qO- https://raw.githubusercontent.com/starkugz/csqtt-openwrt/main/install-v2.0.sh | ash
```

Меню предлагает:

1. Только панель LuCI 2.0.
2. Панель и ядро 2.1.9.
3. Панель и ядро 2.5.1.
4. Только ядро 2.1.9.
5. Только ядро 2.5.1.
6. Оба ядра без панели.
7. Оба ядра и панель.

**0 — Отмена.**

Доступность пакетов зависит от архитектуры и линии OpenWrt. Предыдущий выпуск не содержит MIPS-пакетов; для MIPS используйте [текущий комплект](../v2.5/install.md).

Сохраняйте конфигурацию перед сменой комплекта. Версия клиентского ядра должна соответствовать серверу и профилю. Установка старой панели сама по себе не меняет протокол уже установленного ядра.

## Только панель 2.0

Если ядра менять не нужно:

```sh
wget -T 30 -qO- https://raw.githubusercontent.com/starkugz/csqtt-openwrt/main/install.sh | ash -s -- 2.0
```

Для просмотра плана добавьте `--dry-run` после `2.0`. [Описание прежнего выпуска](RELEASE.md).
