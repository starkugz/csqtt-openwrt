# Файлы выпусков

## Текущий выпуск

[CSQTT 2.5.3](https://github.com/starkugz/csqtt-openwrt/releases/tag/v2.5.3): клиентские ядра **2.5.3** и **2.1.9**, необязательная панель **CSQTT 2.5**.

- OpenWrt 24.10.8: пакеты `.ipk`, менеджер `opkg`.
- OpenWrt 25.12.5: пакеты `.apk`, менеджер `apk`.
- SNAPSHOT: используйте только пакет для указанной в имени архитектуры и линии.
- Установщик автоматически подбирает доступные пакеты по устройству.
- `SHA256SUMS` содержит контрольные суммы пакетов.

[Установка на роутер](install-v2.5.3.md) · [Установка сервера](server-v2.5.3.md) · [Состав текущего выпуска](MANIFEST-v2.5.3.txt)

## Предыдущий выпуск

[CSQTT 2.0](https://github.com/starkugz/csqtt-openwrt/releases/tag/v2.0) сохранён отдельно. Для установки только прежней панели используйте команду для версии **2.0** из [инструкции установки](install-v2.5.3.md).
