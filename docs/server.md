# Сервер CSQTT на Linux / VPS

[Актуальная установка сервера](server-v2.5.3.md): меню предлагает сервер **2.5.3** для x86-64, ARM64 и ARMv7, либо сервер **2.1.9** для x86-64.

Сервер устанавливается на VPS; панель **CSQTT 2.5** и клиентское ядро устанавливаются на роутер [отдельно](install-v2.5.3.md).
