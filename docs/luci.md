# Панель LuCI: страницы

Открывается в LuCI по адресу **Службы → CSQTT**. Интерфейс панели **всегда на
русском** независимо от языка остального LuCI. Отображаемые версии: панель
**2.0**, ядра **2.1.9** и **2.5.1**.

## Страницы

- **Статус** — служба, интерфейс `csqtt0`, активный профиль, состояние сессии,
  передача данных и скорость RX/TX, метрики процесса (CPU, RSS), кнопки
  «Запустить» / «Остановить» / «Перезапустить», последняя ошибка и история
  переключений.
- **Профили** — список серверов, добавление и редактирование (**Добавить
  профиль**, **Импортировать ссылку**), ручной и автоматический выбор сервера,
  импорт/экспорт ссылки `csqtt://`, QR, включение профиля, **выбор ядра**
  (2.1.9 / 2.5.1), при необходимости — расширенные поля (`vk_hash_mode`,
  `vk_js_token`) и проверка VK-хешей (**Проверить хеши**).
- **Настройки** — глобальные параметры: failover/failback, health, CAPTCHA,
  логирование, routing, `persistent_tun`.
- **Журналы** — журнал `/var/log/csqtt.log` (хвост, обновление, очистка).
- **CAPTCHA** — активные задачи, отмена, ссылка и QR-код для Web Helper.
- **О программе** — версии редакции и установленных ядер (live из
  `status.json`), автор, исходный проект, лицензия и уведомления.

## Работа с профилями и ядрами

- Серверных профилей может быть **несколько**, активный — **ровно один**.
  Переключение профиля меняет сервер **единственного** туннеля (краткий перерыв
  передачи допустим). Второго интерфейса и второго экземпляра службы нет.
- Каждый профиль выбирает движок `core_version` (`auto` / `2.1.9` / `2.5.0`).
  Если выбранный пакет ядра не установлен, движок недоступен и профиль
  блокируется с причиной.
- `failover`/`failback` действуют **внутри** единственного пула профилей; они
  не включаются автоматически.

## Секреты

Поля `password` и `vk_js_token` — **write-only**: пустое значение при сохранении
сохраняет прежнее; сохранённое значение никогда не подставляется обратно в
редактор и не выводится в `status`/логах. `device_id` не регенерируется.

## Язык и переводы

- Строки в исходниках панели — английские (`_('English source')`), русский
  перевод — в каталоге `po/` (`po/ru/csqtt.po`).
- Перевод **встроен** в пакет панели; отдельный `luci-i18n-csqtt-ru` не нужен.
- Панель показывает русский, не меняя язык остальных страниц LuCI и глобальные
  настройки OpenWrt.
