# Обновление, откат и удаление

## Общее

- Ядра и панель обновляются **независимо**; можно обновить одно ядро, оставив
  второе прежним.
- `/etc/config/csqtt`, профили, пароли, токены, VK-хеши и `device_id`
  сохраняются как conffile. **`device_id` не регенерируется** — он привязан к
  паролю на сервере.
- Пакеты не подписаны ключом OpenWrt, поэтому apk нужен `--allow-untrusted`.
- После замены пакетов перезапустите службу: `service csqtt restart`.
- Имена файлов при обновлении меняются только по версии/release/архитектуре;
  внутренние имена пакетов (`csqtt-core-2.5.0` и т. д.) остаются теми же.

## Обновление

Скачайте новый набор в `/tmp`, проверьте по `SHA256SUMS` и установите.

**OpenWrt 25.12.x / SNAPSHOT (`apk`):**

```sh
apk add --allow-untrusted /tmp/csqtt-core-2.1.9-openwrt-25.12-aarch64_cortex-a53.apk
apk add --allow-untrusted /tmp/csqtt-core-2.5.1-openwrt-25.12-aarch64_cortex-a53.apk
apk add --allow-untrusted /tmp/luci-app-csqtt-2.0-openwrt-25.12.apk   # необязательно
service csqtt restart
```

**OpenWrt 24.10.x (`opkg`):**

```sh
opkg install /tmp/csqtt-core-2.1.9-openwrt-24.10-aarch64_cortex-a53.ipk
opkg install /tmp/csqtt-core-2.5.1-openwrt-24.10-aarch64_cortex-a53.ipk
opkg install /tmp/luci-app-csqtt-2.0-openwrt-24.10.ipk   # необязательно
service csqtt restart
```

### Про флаги `opkg`

`opkg` без флага может **молча ничего не поменять и завершиться успехом**:

- если новый номер пакета **меньше** установленного — печатает
  `Not downgrading package …`; нужен `--force-downgrade`;
- если номер **совпадает** (замена содержимого того же выпуска) — печатает
  `… installed in root is up to date`; нужен `--force-reinstall`.

`apk` с явно указанным файлом и понижает, и заменяет содержимое сам (проверено
на apk-tools 3.0.5), флаг ему не нужен. Автоустановщик подбирает флаги
автоматически и после установки проверяет, что версия действительно сменилась.

## Откат

Откат — установка прежних файлов пакетов с понижением версии и перезапуск
службы.

```sh
apk add --allow-untrusted /tmp/<прежний-файл-ядра>.apk
apk add --allow-untrusted /tmp/<прежний-файл-панели>.apk   # если обновляли
service csqtt restart
```

Профили и `/etc/config/csqtt` при откате **не пересоздаются**, но их следует
сверить: если откатываетесь на сборку без поддержки схемы 3, восстановите
резервную копию конфигурации схемы 1/2 — старый бинарник не понимает
независимые настройки профилей. Резервные копии конфигурации храните отдельно и
`0600`.

## Удаление

**Скриптом (рекомендуется):**

```sh
wget --no-proxy -qO /tmp/csqtt-uninstall.sh https://raw.githubusercontent.com/starkugz/csqtt-openwrt/v2.0/uninstall-csqtt.sh \
  && ash /tmp/csqtt-uninstall.sh
```

Скрипт: останавливает службу, снимает автозапуск, удаляет **только** пакеты
CSQTT (панель, оба ядра, при наличии — legacy-перевод), пропускает
отсутствующие. `/etc/config/csqtt` перед удалением копируется в защищённый
временный каталог и восстанавливается, если менеджер его снёс. Маршрутизацию,
DNS, firewall, Mihomo/Podkop и серверную часть на VPS скрипт **не трогает**.

**Вручную:**

```sh
service csqtt stop
service csqtt disable
apk del luci-app-csqtt csqtt-core-2.1.9 csqtt-core-2.5.0   # apk
# opkg remove luci-app-csqtt csqtt-core-2.1.9 csqtt-core-2.5.0   # opkg
```

> На OpenWrt 25.12+ `apk del` по своей семантике дополнительно убирает
> автоматически установленные зависимости, которые больше никому не нужны;
> зависимости, нужные другим пакетам или базовой системе, остаются. `opkg`
> зависимости не трогает. При ручном удалении сделайте копию
> `/etc/config/csqtt` заранее — скрипт делает это сам, команды `apk del`/`opkg
> remove` — нет.

## Обновление только ядра

Пакеты ядер и LuCI независимы. Следующая команда скачивает новый установщик,
выбирает только ядро 2.5.1, сохраняет панель и конфигурацию, а после успешной
установки перезапускает службу для загрузки нового ядра:

```sh
wget --no-proxy -qO /tmp/csqtt-install.sh https://raw.githubusercontent.com/starkugz/csqtt-openwrt/main/install-csqtt.sh \
  && ash /tmp/csqtt-install.sh --set core-2.5.1 \
  && service csqtt restart
```

Для ядра 2.1.9 замените состав на `--set core-2.1.9`; для обоих — `--set cores`.
По умолчанию выбирается последний опубликованный выпуск. Для закреплённого
выпуска задайте `CSQTT_VERSION=<тег>` перед `ash`. Панель и перевод не
скачиваются, не удаляются и не переустанавливаются. Профили и `device_id`
сохраняются. Короткий разрыв туннеля при перезапуске ожидаем.

Если новая версия требует несовместимый интерфейс управления, установщик
останавливается до изменений: обновление панели должно быть отдельным
осознанным действием. Возможность будущего обновления без LuCI сохраняется
при совместимости её API; автоматической подмены панели нет.

## Смена ядра без переустановки

Выбор движка для профиля задаётся ключом `core_version`:

```sh
# myserver — ID конкретного профиля из csqtt profile list:
csqtt profile set myserver core_version 2.5.0
service csqtt restart
```

Версия задаётся отдельно для каждого профиля; глобального main.core_version нет.
Внутренний ключ 2.5.0 соответствует отображаемому ядру 2.5.1.
Если пакет выбранного ядра не установлен, движок недоступен: панель не
предлагает его и `auto` как рабочий, профиль блокируется с причиной. Подмены
одного ядра другим нет.
