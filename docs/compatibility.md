# Совместимость с прокси-клиентами

CSQTT создаёт сетевой интерфейс `csqtt0`, но сам трафик в туннель не направляет.
Направляет его **прокси-клиент**, который умеет привязывать исходящие соединения
к интерфейсу. Через туннель пойдёт только тот трафик, который клиент по своим
правилам отправит на этот интерфейс.

## Термины

- **`csqtt0`** — *сетевой интерфейс* в системе; его создаёт CSQTT. Это
  единственный туннель.
- **Прокси-клиент** — программа на роутере (Mihomo, SSClash, Podkop, Forkop,
  ZeroBlock), которая решает, какой трафик куда отправлять.
- **Выход** (outbound, proxy) — *элемент конфигурации клиента*, а не интерфейс.
  Он описывает, как отправлять соединения. Выход с полем
  `interface-name: csqtt0` означает: «отправлять соединения через интерфейс
  `csqtt0`». Отдельный TUN или второй сетевой интерфейс в OpenWrt для этого
  **не нужен** — `csqtt0` уже создан CSQTT.
- **Группа выбора** (proxy-group) — список выходов, между которыми пользователь
  выбирает.
- **Правила** (rules) — список «какой трафик в какой выход»; проверяются
  **сверху вниз**.

## Пример для Mihomo

```yaml
proxies:
  - name: CSQTT
    type: direct
    interface-name: csqtt0
    udp: true
```

`ssclash` (<https://github.com/zerolabnet/SSClash/>) и другие клиенты,
поддерживающие привязку к интерфейсу через `SO_BINDTODEVICE`, настраиваются
аналогично: в качестве выхода указывается `csqtt0`.

## Что важно помнить

- CSQTT **не** добавляет маршруты, правила, таблицы и **не** трогает системный
  DNS/dnsmasq, firewall и NAT ([сетевой контракт](network-contract.md)).
- Control-plane CSQTT/VK/TURN идёт через WAN и в привязку не входит.
- Проверить, что трафик действительно идёт через туннель, можно командой:

```sh
curl --interface csqtt0 --max-time 15 https://1.1.1.1/cdn-cgi/trace
```

Если внешний IP в ответе — IP сервера CSQTT (а не WAN), привязка работает.

> Конкретные клиенты и их версии в этом выпуске отдельно не проверялись. Здесь
> описан общий механизм (`SO_BINDTODEVICE`), достаточный для любого клиента,
> поддерживающего привязку исходящих соединений к интерфейсу.
