# Совместимость с прокси-клиентами

CSQTT создаёт один интерфейс **`csqtt0`**. Через него можно направлять выбранный трафик в Mihomo, SSClash, Podkop и других клиентах, поддерживающих выбор существующего сетевого интерфейса. Для ZeroBlock и Forkop используйте версию и режим с такой возможностью.

CSQTT сам не перенаправляет весь домашний трафик. Правила и выбор выхода задаются в используемом прокси-клиенте; WAN, системный DNS, маршруты и firewall установщик CSQTT не перенастраивает.

При `persistent_tun=1` интерфейс сохраняется при отключении от сервера, смене профиля и остановке/запуске службы. Передача данных возобновляется после восстановления соединения. Удаление последнего ядра удаляет интерфейс.
