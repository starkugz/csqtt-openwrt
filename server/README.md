# Сервер CSQTT

Выполните на Linux VPS с systemd. Меню позволяет выбрать сервер 2.1.9 для x86-64 или 2.5.3 для x86-64, ARM64 и ARMv7.

```sh
curl -fsSL https://raw.githubusercontent.com/starkugz/csqtt-openwrt/main/install.sh | sudo sh
```

Установщик определяет архитектуру и сверяет SHA-256. Бинарники находятся в [v2.5.3](v2.5.3/), лицензия и уведомления лежат рядом.
